# Design notes

How the features in Caption Mode were thought through before they were built.

- `specs/` — what a feature should do, and why it is shaped that way
- `plans/` — the step-by-step build order that followed from a spec

These are a record, not documentation. They describe the state of things when
they were written and are not updated as the code moves on. For how Caption Mode
works today, read the [README](../../README.md).
